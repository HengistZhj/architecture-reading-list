# 建筑书单维护 / Reading-list maintenance

- 本仓库是长期积累的建筑书单；阅读数据只在`books.json`维护。 / This is a long-term architecture reading list; maintain reading data in `books.json`.
- 保持有效JSON；不经明确要求，不删除书籍或重设计网站。 / Keep valid JSON; do not delete readings or redesign the site without an explicit request.
- 界面、分类、状态和说明保持中英双语。 / Keep interface labels, categories, statuses and descriptions bilingual.
- 保留英文原书名；中文未确认正式出版译名时标为参考译名，不编造作者、年份或链接。 / Retain original English titles; label unverified Chinese titles as reference translations and never invent authors, years or URLs.
- 同时维护`title`/`title_zh`、`notes`/`notes_zh`，以及中文分类与状态字段。 / Maintain paired title and note fields and Chinese category/status fields together.
- 保留原有状态、优先级、课程来源，优先复用现有分类。 / Preserve existing progress, priorities and course sources; reuse categories where appropriate.
- 来源明确时保留Primary/Supplementary；未指定的新项默认Supplementary、优先级3、Not started。 / Preserve stated Primary/Supplementary labels; unspecified new entries default to Supplementary, priority 3, Not started.
- 优先级为1–5整数；状态仅用Not started、Reading、Finished、Reference。 / Priority must be an integer from 1 to 5; use only the four existing status values.
- 中英文说明各用一句简洁的话；不把未读书籍写成读后感。 / Keep each language's note to one concise sentence and do not present unread books as completed reading.
- 有链接就保留，不要求逐条验证可访问性。 / Preserve supplied URLs without requiring individual availability checks.
